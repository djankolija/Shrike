# What is a Mutex?

A **mutex** (short for "mutual exclusion") is a synchronization primitive used to protect shared resources from concurrent access by multiple threads or processes. Think of it as a lock that ensures only one thread can access a particular piece of data or code at a time.

## How It Works

The basic pattern is:

```
lock the mutex
  ... access the shared resource ...
unlock the mutex
```
